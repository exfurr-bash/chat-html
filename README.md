# Chat Kawaii ✨💖

Bem-vinda(o) ao Chat Kawaii, um sistema de chat simples com login, registro e mensagens em tempo real utilizando **Flask**, **Socket.io**, e **SQLite**! 🐾

## 🌸 Features:

- **Login**: Autenticação de usuários com nome de usuário e senha 🦄
- **Registro**: Crie uma conta para acessar o chat 💌
- **Chat em tempo real**: Mensagens são enviadas e recebidas instantaneamente 🎉
- **Banco de dados SQLite**: Armazena usuários e mensagens com amor 💾
- **Interface Responsiva**: Funciona tanto em desktop quanto mobile 📱💻

## 🛠️ Tecnologias Utilizadas:

- **Flask**: Framework web em Python para backend 🐍
- **Socket.io**: Comunicação em tempo real para o chat 💬
- **SQLAlchemy**: ORM para gerenciamento de banco de dados em SQLite 💎
- **Flask-Login**: Gerenciamento de sessões e autenticação de usuários 🔐
- **SQLite**: Banco de dados leve e rápido 🗃️

## 📦 Como rodar o projeto?

### Pré-requisitos:

1. **Instalar Python** (versão 3.x)
2. **Instalar as dependências**:

```bash
pip install -r requirements.txt
```

### Rodando o projeto:

1. Clone este repositório:

```bash
git clone https://github.com/exfurr-bash/chat-html.git
cd chat-html
```

2. Execute o servidor Flask com o Socket.io:

```bash
python app.py
```

3. Abra o navegador e acesse:

```
http://localhost:5000
```

Pronto! Agora você pode entrar e começar a bater um papo com a galera no chat! 🦋💕


# Chat Kawaii ✨💖

Bem-vinda(o) ao Chat Kawaii, um sistema de chat com mensagens em tempo real, login fofinho, e agora com uma IA fofa chamada Kokoro-chan que interage com você em tempo real! UwU

# 🌸 Features:

Login & Registro: Autenticação de usuários com nome de usuário e senha, tudo bem cuti-cuti! 🦄

Chat em tempo real: Mensagens são enviadas e recebidas instantaneamente com muito amor e glitter 🎉

IA Kokoro-chan: Uma IA fofa, atrevida e cheia de energia que responde quando você chama por @kokoro ✨💬

Geração de respostas usando Gemini: As respostas da Kokoro-chan são geradas com inteligência artificial (Gemini 1.5 Flash) diretamente do Google! 🤖

Memória de contexto: A IA lê as últimas mensagens pra manter o papo fluido e contextualizado (sem surtar falando com ela mesma hehe) 🧠

Banco de dados SQLite: Armazena usuários e mensagens com carinho 💾

Interface Responsiva: Perfeita tanto pra desktop quanto pra mobile 📱💻


# 🛠️ Tecnologias Utilizadas:

Flask: Framework web em Python que é a base de tudo! 🐍

Socket.io: Comunicação em tempo real pra aquele bate-papo ao vivo 💬

SQLAlchemy: ORM que faz o banco funcionar lindamente 💎

Flask-Login: Gestão de autenticação e sessões 🔐

SQLite: Banco de dados leve e sem frescura 🗃️

Gemini (via API): A IA que dá vida à Kokoro-chan 💖


# 📦 Como rodar o projeto?

Pré-requisitos:

1. Python 3.x instalado


2. Cria o arquivo .env com sua chave da API Gemini:



GEMINI_API_KEY=sua_chave_lindinha_aqui

3. Instala as dependências:



pip install -r requirements.txt

Rodando o projeto:

git clone https://github.com/exfurr-bash/chat-html.git
cd chat-html
python app.py

Acesse no navegador:
http://localhost:5000

# ✨ Como chamar a IA?

É só mandar uma mensagem mencionando a @kokoro (com "k" minúsculo mesmo) que ela aparece toda kawaii e pronta pra brilhar com você!

Exemplo:
@kokoro me conta uma piada fofa!
